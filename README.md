# Fundingstories

Fundingstories turns a set of keywords into a short story inspired by biographies and literary history. Stories are generated by Gemini and include a list of inspirations.

- Generates a story from up to 200 characters of keywords.
- Stores the latest 20 stories in browser localStorage under `findingstories_history`.
- Allows reopening a previous story.
- Supports copying the story and downloading a PDF.
- Stories are generated by AI and may contain inaccuracies.
